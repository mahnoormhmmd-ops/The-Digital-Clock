⏰ Digital Clock

The Digital Clock is a simple and efficient web application made with HTML, CSS and JavaScript. It displays time in the 12 hour format, efficiently synchronizing the hours, minutes, and seconds and the AM/PM with that of the device. It updates every seconds, showing the seconds passing with Javascript's Date() and setInterval() functions.

This project is made with a glass-style interface with a custom background image, and the CSS flex ox, which makes it working in both mobile and desktop. It is a beginner friendly project that helps us learn about DOM manipulation and real time data updates.

Through this project, I learned to work with Java's DOM elements, API, Date(), and building responsive formats with HTML and CSS. Future improvements include adding a dark/light mode option, a date display, customizing the bbackground image, and adding different timezones of the world, and 24 hour format as well with the 12 hour one.
