# ⏰ Digital Clock

A modern and responsive **Digital Clock** built using **HTML**, **CSS**, and **JavaScript**. The clock displays the current time in a 12-hour format with **Hours**, **Minutes**, **Seconds**, and **AM/PM** indicators. It updates automatically every second without requiring the page to refresh.

## 📖 Description

This project demonstrates how JavaScript can interact with the browser's **Date API** to create a live digital clock. The interface features a clean layout, translucent clock panels, and a customizable background image, making it a great beginner-friendly project for learning DOM manipulation and real-time updates.

## ✨ Features

- 🕒 Real-time digital clock
- ⏱️ Updates every second automatically
- 🌙 12-hour time format (AM/PM)
- 🎨 Modern glass-style clock design
- 🖼️ Custom background image
- 📱 Responsive layout using Flexbox

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
